## ⑤工夫した点・こだわった点
- 自分の手を使って、リアルにじゃんけんが楽しめるようこだわりました。
　じゃん、けん、ぽい、のタイミングをとりやすくするために、テキストに
　FadeOut効果を入れたり、あいこになった時の間を調整しました
- じゃんけん「ぽい」の瞬間、実際の人間の手は一瞬グーになりがち
　であることに気づき、画像認識の判定を0.2秒ずらしました
- 後出しをすると負けるようにしました（「ぽい」の後、0.3秒後までに
　手が判定できないと、後出しで負けとなります）

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 画像認識の性能をもっと試したいので、次はバスケやサッカーの
　自動得点判定を試したいです（誰がシュートを打ったのか、
　入ったのか、入らなかったのか、など）。
- 音声認識をさせて、ゲームの種類を選べるようにしてみたいです。
