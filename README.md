# Janken_Rich
Gs課題
# ①課題名
じゃんけんアプリRich ver

## ②課題内容（どんな作品か）
- Webカメラで捉えた手の形状からグーチョキパーを判定し、
　じゃんけんができます
- 画像認識にMediaPipeライブラリを利用しており、
　ブラウザが自動で下記を読み取っています。
    ・MediaPipe 本体（JavaScript）
    ・手を認識する処理（WebAssembly）
    ・手の認識モデル

## ⑤工夫した点・こだわった点
- 自分の手を使って、リアルにじゃんけんが楽しめるようこだわりました。
　じゃん、けん、ぽい、のタイミングをとりやすくするために、テキストに
　FadeOut効果を入れたり、あいこになった時の間を調整しました
- じゃんけん「ぽい」の瞬間、実際の人間の手は一瞬だけグーになりがち
　であることに気づき、画像認識の判定を0.2秒ずらしました
- 後出しをすると負けるようにしました（「ぽい」の後、0.3秒後までに
　手が判定できないと、後出しで負けとなります）

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 画像認識の性能をもっと試したいので、次はバスケやサッカーの
　自動得点判定を試したいです（誰がシュートを打ったのか、
　入ったのか、入らなかったのか、など）。
- 音声認識をさせて、ゲームの種類を選べるようにしてみたいです。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- [感想]
　画像認識コードが思った以上に簡単に呼び出せて、精度も高くて
　驚きました。もっと使い込んで、機能を自分で拡張していけるように
　していきたいです。
　Claude Codeを使っていると、実際の指示以上に、勝手に作り込んで
　しまうことがあるので、講義であったように、部品に分けて指示を出す
　ということを徹底したいと思いました。
　まだコードを理解しきれていないので、何度もいじくって、全体の
　構造を理解したいと思います。
